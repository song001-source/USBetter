# 架构与检查边界

`src/UsbTetherHelper.cpp`：Win32 隐藏窗口、托盘、CM USB 通知、实例文件锁、当前登录令牌 AuthenticationId、接入状态持久化、命名管道与动作队列、超时及作业对象清理。状态在启动连接子进程前落盘；因此崩溃可能使本次尝试未完成，但不会靠重启不断抢回手机模式。用户可以明确重新检测。

`scripts/Core.ps1`：纯解析与关联规则、网卡就绪判断、Windows 参数引用、原子配置读写。

`scripts/Helper.ps1`：依赖与服务协议检查、拓扑枚举、授权等待、设备选择、一次性共享验证、配置保存、设置安装、计划任务、卸载与脱敏诊断。使用现有 5037 服务；无服务时通过 WMI 创建服务启动客户端，使长期 ADB 服务不属于连接子进程的清理作业。没有调用 `kill-server`。ADB 客户端每次有超时限制。

PowerShell 连接流程总窗口 120 秒，原生端 125 秒兜底并清理整个连接作业。设置/选择对话框可等待用户；未授权轮询不使用阻塞确认框。仅设备事件触发只读网卡快照，空闲时没有 PowerShell 网络轮询。托盘每两秒读取本地状态文字。

自动候选仅来自本次推断新接入的 USB 序列尾段，仍需经过完整唯一身份验证；若已有活跃手机，则优先保留它。状态只反映最近快照，不是实时外网监控。USB 拓扑不符合严格关联规则的手机可能本来能共享，但工具仍拒绝自动操作。

测试分层：纯数据身份/网卡/配置测试；原生状态机与系统命令行解析测试；使用临时数据目录、模拟依赖的流程测试；只读本机拓扑核验；最后是需用户操作和额外硬件的实机验收。前几层不能证明最后一层已通过。

已知工程限制：二进制尚未签名，可能触发 SmartScreen；本地哈希非发行者认证。当前不处理多用户同时争用同一部手机的 ADB 模式控制。崩溃与 USB 模式变化之间存在无法消除的时序窗口。升级是备份加恢复，不是跨进程/计划任务的事务；需实机故障注入覆盖电源中断和文件占用。
